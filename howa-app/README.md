# 法話の種

日常の気持ちを入口に、法話の切り口をまとめて出す下ごしらえ帳。

## つくりの考え方

教義から降りていくのではなく、**一般の人が実際に立ち止まる場面**（既読がつかない、同級生の新築、免許返納…）から始めて、そこから仏教へ渡す。
同じ気持ちから **12通りの切り口** を回して出すので、「その話はもう何度も聞いた」となりにくい入口を探せる。

素材はすべてアプリの中に持っている。外部APIもサーバーも使わない（入力も保存も端末のブラウザの中だけ）。

## 素材の構造

| ファイル | 中身 | 役割 |
| --- | --- | --- |
| `src/data/emotions.ts` | 気持ち 28種 | 一般の人が自分の言葉で選ぶ入口 |
| `src/data/concepts.ts` | 仏教語・教義 46種 | `misread`（世間の受け取り）→ `pivot`（仏教から見たズレ）の対で持つ |
| `src/data/stories.ts` | 喩え・逸話 27種 | そのまま語れる長さの要約と使いどころ |
| `src/data/words.ts` | 日常語になった仏教語 27種 | 我慢・億劫・大丈夫…「入口を広く」する主力 |
| `src/data/modern.ts` | 現代の場面 44種 | 法話の一行目に使う語り出し |
| `src/data/occasions.ts` | 年中行事 14種 | 季節に寄せる切り口の素材 |
| `src/data/angles.ts` | 切り口 12種・場面 6種 | 裏返し／語源ひらき／逆説／こじつけ全開 など |

素材を足すときは、同じ形で配列に追記するだけでよい。
`npm test` が、感情タグの実在・idの重複・どの気持ちにも素材が揃っているかを見ている。

## 出力

- **法事・月参り・法話会**：入口 → ひっかかり → 仏教のことば → 視座のズレ → 落とし込み → 結び ＋ 語り手向けの演出メモ
- **掲示板・SNS**：一行の案3つ ＋ 短文 ＋ 聞かれたときの仕込み

「見出しつきコピー」は推敲用（出典・メモ込み）、「通し原稿コピー」はそのまま読める形（メモは外れる）。

## 出典の扱い

出典は通称で記している。**人前で語る前に原典を確認すること**を前提にしている。
語源や逸話に諸説あるもの（諦める、油断、白隠「そうか」など）はカードの「語る前に確認」に出る。

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # データとネタ生成のテスト
npm run typecheck
npm run build      # dist/ に静的ファイル
```

ビルド結果は静的ファイルのみ。`vercel.json` を置いてあるのでそのまま配信できる。
