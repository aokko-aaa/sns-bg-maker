# 青色帳簿

個人事業の青色申告（65万円控除）向けの帳簿アプリ。`index.html` 1ファイルで動きます（ビルド不要）。

## できること
- かんたん入力（売上・経費・振替）→ 複式仕訳を自動作成
  - 家事按分（事業割合を選ぶと家事分を事業主貸に分けて記帳）
  - 源泉徴収（報酬の10.21%／100万円超は20.42%）を事業主貸で記帳
- 仕訳帳（月・キーワード絞込、編集、削除）／総勘定元帳
- 損益計算書（青色申告決算書・一般用の欄番号つき）、月別売上・仕入、貸借対照表
- 固定資産の減価償却（定額法）→ 12/31付で仕訳に反映
- 翌年の帳簿作成（期末残高を期首残高へ繰越、元入金を再計算）
- 仕訳帳CSV（Excel用BOM付き）・JSONバックアップ／復元

## 保存先
- claude.ai のアーティファクトとして開いた場合：あなた専用のクラウド保存（`data/users/<id>/`）
- このファイルを直接ブラウザで開いた場合：その端末の localStorage（設定画面からバックアップを保存してください）

## 未対応
専従者給与、貸倒引当金、消費税（課税事業者・インボイス対応の税区分）、不動産所得用の決算書。
